# 🚀 Xautomatic-Post  
A simple Python bot that automatically posts tweets at regular intervals using the **Twitter API** and the **Tweepy** library.

---

## 📌 Features  
✅ Automatically tweets every **5 minutes**  
✅ Uses a **random phrase** from a predefined list  
✅ Twitter API integration with OAuth2  
✅ Simple and lightweight script  

---

## 🔧 Installation  

### **1️⃣ Clone the Repository**  
```
git clone https://github.com/2saleh1/Xautomatic-Post.git
cd Xautomatic-Post
```
### **2️⃣ Install Dependencies**  
```
pip install tweepy
```
##🛠️ Setup
### **1️⃣ Get Your Twitter API Keys**
You need the following API credentials from Twitter Developer Portal:

. API Key
. API Key Secret
. Bearer Token
. Access Token
. Access Token Secret

### **2️⃣ Add Your API Keys**
Open PostBOT.py and replace the empty strings with your Twitter API credentials:
consumer_key = "your_api_key"

consumer_secret = "your_api_key_secret"

bearer_token = "your_bearer_token"

access_token = "your_access_token"

access_token_secret = "your_access_token_secret"

##▶️ Usage
To start the bot, run:
```
python PostBOT.py
```
